# C4.5 data boundary

The C4.5 tables separate raw validation observations, encoded feature values, historical training labels, model predictions, and human-reviewed recommendations. `c45_training_records.target_value` is the explicit historical label; a prediction must never be copied into it automatically.

Only a model with `model_status = 'ACTIVE'` should generate production recommendations. Every recommendation can have factor rows for explainability and carries confidence plus a `NORMAL`, `INTERVENTION`, or `REVIEW_REQUIRED` state. This is decision support only: no fertilizer, vitamin, or other intervention order is created automatically.

Training, activation, recommendation generation, and review should each run in a transaction and write an `audit_logs` row.
